# Lib

Contiene configuraciones de librerías de terceros y utilidades base que actúan como adaptadores para el proyecto.
Ejemplos:
- `supabase.ts`: Instancia del cliente de Supabase.
- `utils.ts`: Clase utilitaria para tailwind-merge y clsx (típico `cn`).

Si cambias de librería en el futuro, los cambios deberían idealmente encapsularse aquí.
