# Types

Contiene todas las definiciones de tipos globales, interfaces de TypeScript y esquemas de validación (Zod) que se utilizan en múltiples partes del sistema.

Ejemplos:
- `database.types.ts`: Tipos autogenerados de Supabase.
- `models.ts`: Interfaces puras de los datos de la app.

Nota: Si un tipo es exclusivo de un feature, colócalo en `src/features/[feature]/types/`.
